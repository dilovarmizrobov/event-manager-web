# Event Manager Web

Веб-клиент системы по проведению и контролю мероприятий: регистрация гостей, генерация и печать бейджей, проверка гостей по штрихкоду и разграничение доступа по ролям.

Первая версия использовалась на Второй международной конференции высокого уровня «Вода для устойчивого развития, 2018–2028 годы» (Душанбе, июнь 2022). Сейчас продукт развивается как SaaS-платформа [eventy.biz](https://eventy.biz/).

## Возможности

- **Мероприятия и площадки** — создание и редактирование мероприятий, мест проведения, завершение мероприятия.
- **Гости** — список с пагинацией, поиском и фильтрами; создание и редактирование; категории гостей (обычный / VIP).
- **Импорт из Excel** — массовая загрузка гостей (zip-архив с таблицей и фотографиями).
- **Экспорт в Excel** — выгрузка списка гостей.
- **Бейджи** — шаблоны бейджей, генерация бейджей с QR-кодом и пакетная печать в PDF, учёт выдачи бейджа гостю.
- **Проверка по штрихкоду** — сканирование бейджа и отображение карточки гостя (фото, паспорт, страна, категория, отметка о проходе).
- **Справочники** — страны, пользователи.
- **Дашборд и журнал действий** — статистика по мероприятию и лог действий пользователей.
- **Безопасность** — авторизация, обязательная смена пароля при первом входе, ролевая модель доступа.
- **Интерфейс** — светлая и тёмная темы.

## Роли

| Роль | Описание |
|------|----------|
| `ADMIN` | Администратор системы: мероприятия, пользователи, все справочники |
| `ADMIN_EVENT` | Администратор мероприятия: площадки, гости, бейджи, импорт |
| `EMPLOYEE` | Сотрудник: регистрация гостей, печать и выдача бейджей, проверка |
| `GUARD` | Охранник |

Матрица прав описана в [`src/constants/permissions.ts`](src/constants/permissions.ts), проверка — в [`src/utils/hasPermisson.ts`](src/utils/hasPermisson.ts).

## Запуск

Требования: Node.js 14+, Yarn.

```bash
yarn install
yarn start
```

Приложение откроется на [http://localhost:3000](http://localhost:3000). Запросы к API (`/event-manager`) проксируются на бэкенд, адрес которого задаётся полем `proxy` в `package.json`.

Сборка production-версии:

```bash
yarn build
```

## Docker

Приложение собирается многоэтапным `Dockerfile`: сборка на Node.js, раздача статики через Nginx. Конфигурация Nginx — [`nginx/default.conf`](nginx/default.conf): SPA-роутинг и проксирование `/event-manager/` на сервис `event-manager-service:8080`.

```bash
docker-compose build
```

Для развёртывания используются `docker-swarm.yml` и пайплайны Jenkins (`Jenkinsfile`, `Jenkinsfile-prod`).
